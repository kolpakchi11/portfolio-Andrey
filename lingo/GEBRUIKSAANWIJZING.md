# Gebruiksaanwijzing Lingo

## 1. De applicatie starten

Voor het uitvoeren van het Lingo-spel is Python nodig.

### Benodigdheden

- Python 3.13
- Visual Studio Code
- Git (voor versiebeheer)
- De benodigde Python libraries

De applicatie bestaat uit meerdere Python-bestanden:

- `Main.py` – startpunt van het programma
- `Functions.py` – bevat de functies van het spel
- `Data.py` – bevat de woordenlijst

Zorg ervoor dat alle bestanden in dezelfde projectmap staan.

### Python controleren

Open de terminal in Visual Studio Code en controleer de Python-versie:

```bash
python --version
