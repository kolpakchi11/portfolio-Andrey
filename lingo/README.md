# Lingo

## About the project

Lingo is a terminal-based word guessing game for two teams.

The game combines word guessing with a bingo system.

## Features

- Two teams
- Word guessing
- Letter checking
- Bingo card
- Red and green balls
- Score system
- Win and loss conditions
- Colored terminal output
